안성맞춤 AI · 상권 분석

공실 처방 모듈 프로토타입 · 소상공인 상가(상권)정보 API 기반

데이터 설정

proxy.py를 실행한 뒤 http://localhost:8000 주소로 이 페이지를 열어야 합니다. 서비스키는 서버 환경변수에만 두므로 화면에 입력할 필요가 없습니다.
엔드포인트와 응답 필드는 활용신청한 API의 명세 기준으로 확인해 주세요(서비스명이 개편된 이력이 있음). 브라우저 직접 호출이 CORS로 막히면 프록시가 필요합니다.
지도를 클릭하면 분석 중심이 이동합니다. '공실 추가 모드'에서는 클릭한 위치에 공실 후보가 추가됩니다. 공실 위치는 상가정보 API에 없으므로 별도 자료나 직접 입력이 필요합니다.

상권 요약

-업소 수
-업소/㎢
-업종 다양성(0~100)

업종 분포 (클릭하면 지도에서 숨김/표시)

적합 업종 추천

현재는 업종 공급 공백과 접근성 점수를 합산하는 규칙 기반 점수입니다. 이후 AI 모델로 교체할 자리입니다.
