# 안성맞춤 AI · 상권 분석 (데모)

경기도 안성시 상권 분석 페이지의 프로토타입입니다. 공실 처방 모듈의 화면과 분석 흐름을 팀원이 미리 볼 수 있도록 올린 데모입니다.

> **주의:** 현재 화면의 업소·공실 데이터는 모두 **가상의 샘플**입니다. 실제 상가 데이터가 아닙니다.

## 보는 방법

- **GitHub Pages**: 저장소의 Settings → Pages에서 `main` 브랜치 루트를 선택하면 `https://<계정>.github.io/<저장소>/` 주소로 열립니다.
- **로컬**: `index.html`을 내려받아 브라우저에서 열면 됩니다(인터넷 연결 필요, 지도 타일 때문).

## 기능

- 지도를 클릭해 분석 중심 이동, 분석 반경(200~1500m) 조절
- 업소 수, 업소 밀집도, 업종 다양성 지수
- 업종 분포 차트 (클릭하면 지도에서 숨김/표시)
- 공실 후보 선택 시 주변 300m 기준 적합 업종 Top 3 추천
- '공실 추가 모드'로 지도에 공실 후보 직접 추가
- 접근성 점수 슬라이더: 이후 신호 진단 모듈 결과가 들어올 자리

## 현재 한계 / 앞으로 할 일

- 데이터는 데모용 가상 값입니다. 소상공인시장진흥공단 상가(상권)정보 API 연동은 이후 단계입니다.
- 추천은 업종 공백과 접근성을 더하는 규칙 기반 점수이며, 이후 AI 모델로 교체할 예정입니다.
- 지도는 Leaflet과 CARTO 배경지도(OpenStreetMap 데이터)를 사용합니다. 최종 UI에서는 카카오맵 교체를 검토합니다.
