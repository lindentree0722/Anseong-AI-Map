# 안성맞춤 AI

### 교통과 상권을 연결하는 도시 분석 플랫폼

## 프로젝트 소개

**안성맞춤 AI**는 경기도 안성시의 교통 신호, 도로 환경, 상권 데이터를 AI로 분석하여 교통 효율성을 높이고 지역 상권 활성화를 지원하는 웹 플랫폼입니다.

핵심 목표는 **신호 진단 결과를 활용해 공실 처방과 멈춤 없는 길을 구현하는 것**입니다.

## 핵심 기능

###  신호 진단
- 교통 신호 운영 현황 및 효율성 분석
- 불필요한 신호 대기와 정체 구간 파악
- 교통 흐름 개선을 위한 신호 운영 개선안 제시
- 분석 결과를 다른 모듈에 제공

###  공실 처방
- 안성시 상가 공실 위치 지도 시각화
- 주변 업종, 유동인구, 교통 접근성 분석
- 신호 진단 결과를 활용한 접근성 평가
- AI 기반 적합 업종 및 시설 추천

###  멈춤 없는 길
- 출발지와 목적지 기반 경로 탐색
- 교통 신호 및 예상 대기시간 분석
- 신호 진단 결과를 반영한 경로 비교
- 불필요한 정차와 신호 대기가 적은 경로 추천

## 시스템 구조

```text
           [교통 및 도시 데이터]
                    |
                    v
               [신호 진단]
                /        \
               v          v
         [공실 처방]  [멈춤 없는 길]
               \          /
                v        v
             [통합 웹 플랫폼]
```

세 모듈은 단순히 독립된 기능이 아니라 **신호 진단을 중심으로 연결**됩니다.

## 활용 예정 데이터

- 교통 신호등 위치 및 운영 정보
- 도로망 및 교통 소통 정보
- 상가 공실 위치
- 주변 상권 및 업종 분포
- 유동인구 및 주요 시설 정보

공공데이터를 우선 활용하며, 확보하기 어려운 데이터는 대체 자료나 시뮬레이션을 검토합니다.

## 개발 방향

### 백엔드 실행

Python 3.15와 uv를 설치한 뒤 저장소 루트에서 실행합니다.
팀 개발 버전은 `backend/.python-version`의 3.15를 기준으로 합니다.

```powershell
cd backend
uv sync --locked
uv run uvicorn main:app --reload
```

API 문서는 http://127.0.0.1:8000/docs 에서 확인합니다.
실행 중인 서버는 `Ctrl+C`로 종료합니다.
의존성 관리와 현재 API의 제한은 [백엔드 안내](backend/README.md)를 참고하세요.

### 구현 순서

1. 안성시 관련 공공데이터 수집 및 정제
2. 교통 신호 분석 모델 구현
3. 공실 추천 및 경로 탐색 기능 개발
4. 지도 기반 웹 인터페이스 구현
5. 세 모듈 통합 및 결과 검증

## 기대 효과

- 교통 신호 운영의 비효율성 파악
- 불필요한 신호 대기 및 정차 감소
- 상가 공실 활용도 향상
- 데이터 기반 지역 문제 해결 가능성 제시
