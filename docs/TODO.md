# 할 일

현재 구조는 React/Vite 단일 프런트엔드와 FastAPI 백엔드가 연결된 프로토타입이다. 아래 순서는 새 기능보다 실행 재현성과 데이터 신뢰도를 먼저 확보하는 기준이다.

2026-11-27 기준 다음 기능 작업은 **공실 처방 화면 연결**이다. 이후 실제 공실·영업점 자료를 연결하고, 도로망 기반 경로 비교를 구현한다. 안성시 신호 관측은 사용 가능한 원천 자료가 확보될 때까지 보류한다.

## 1. 개발 환경과 검증 기준 고정

- [ ] 운영용 정식 Python 버전을 확정하고 필요하면 `backend/pyproject.toml`, `backend/.python-version`, `backend/uv.lock`, 실행 문서를 함께 맞춘다.
- [ ] 깨끗한 환경에서 `npm ci --prefix frontend`가 성공하는지 확인한다.
- [ ] 백엔드 pytest, 프런트 Node 테스트, 타입 검사, 프로덕션 빌드를 한 번에 확인하고 README의 과거 실행 결과를 현재 결과로 갱신한다.
- [ ] 네 경로(`/`, `/signals`, `/commercial`, `/traffic`)를 브라우저에서 확인하고 콘솔 오류와 모바일 레이아웃을 점검한다.

완료 조건: 새로 받은 저장소에서 문서의 명령만으로 설치·테스트·빌드·실행할 수 있다.

## 2. 배포 화면의 데이터 출처 확인

- [ ] API 실패 시 더미 데이터로 자동 전환되는 화면에서 더미 사용 여부가 항상 눈에 띄는지 확인한다.

완료 조건: 개발 서버 없이 빌드 산출물을 배포해도 각 API 경로가 동작하고, 실측·저장·더미 데이터가 화면에서 구분된다.

## 3. 장소 API 삭제 권한

- [ ] 전체 삭제 API가 실제 사용자 데이터에 연결되기 전 인증 또는 관리자 경계를 설계한다.

완료 조건: 권한이 있는 사용자만 실제 장소 데이터를 전체 삭제할 수 있다.

## 4. 교통 실측 데이터의 유효 범위 확대

- [ ] 현재 단일 `ANSEONG_LINK_ID`와 수동 좌표만 받는 방식을 실제 분석 대상 링크 목록으로 확장할 요구사항을 정한다.
- [ ] 제공기관 응답의 속도 외에 교통량·집계 구간 등 신뢰할 수 있는 필드를 매핑하고 단위를 확인한다.
- [ ] 실측 응답에는 없는 혼잡도·대기시간·녹색 비율을 임의 생성하지 말고, 진단 가능한 지표와 `자료 부족` 상태를 구분한다.
- [ ] 제공기관 오류, 빈 결과, 시간대·좌표·행 수 검증을 유지하면서 실제 응답 샘플 기반 계약 테스트를 추가한다.

완료 조건: 화면의 진단 문구가 실제 수집 필드만 근거로 하며, 출처·관측시각·단위가 추적 가능하다.

## 5. 공실 처방 시연과 실자료 연동

- [ ] `/commercial`에서 공실 API의 목록을 지도와 목록에 표시하고, 공실 선택 시 처방 API의 추천 업종·항목별 점수·데이터 출처를 보여준다. 자료 부족과 조회 실패 상태도 표시한다.
- [ ] 실제 공실과 영업점 자료부터 확보해 연결한다. 공실의 좌표·확인일과 영업점의 업종 코드·기준일을 확인하고, 유동인구·시설·도로 관측 자료는 확보되는 순서대로 교체한다.
- [ ] 상권 공공 API를 실제 서비스키로 검증하고 CORS, 페이지 제한, 빈 응답, 좌표계를 확인한다.
- [ ] 샘플·실자료·혼합 응답의 계약 테스트를 보강하고 화면의 출처 표시를 확인한다.

완료 조건: 화면에서 공실을 선택해 추천 근거와 데이터 출처를 확인할 수 있다.

## 6. 도로망 기반 경로 비교

- [ ] 샘플 도로망의 통행 방향과 회전 제한을 반영해 출발지·목적지 사이의 경로를 계산한다.
- [ ] 구간별 관측 통행시간으로 후보 경로를 비교하고, 관측이 비어 있는 구간의 비용 계산 기준을 정한다.
- [ ] 교통 대시보드에 경로와 예상 통행시간을 연결한다. 신호 대기시간은 사용 가능한 관측 자료 확보 후 추가한다.

## 7. 신호 관측 연동 (보류)

- [ ] 제공기관에 신호 잔여시간 서비스 지역 목록과 안성시 조회 코드를 확인한다. 2026-11-24 비교 조회에서 서울 교차로 위치는 K0(보고 총 2,779건, 첫 페이지 100건 확인), 서울 신호 잔여시간과 경기도·안성시 두 API는 K3(데이터 없음)였다.
- [ ] 안성시 관측이 실제로 반환되면 재발급 키를 Render 서버에 설정하고 공개 목록·상세를 검증한다.

재개 조건: 안성시 관측 자료의 제공 범위와 조회 방법이 확인된다. 공실 처방 API의 신호 평균 대기시간은 그때까지 `null`로 반환한다.

## 8. 저장소 정리

- [ ] 내용이 없는 추적 파일 `feat-sh`가 필요한지 확인한 뒤 불필요하면 삭제한다.
- [ ] `frontend/asdf.html`을 보존할 근거가 없다면 React 홈 화면과 중복되는 대형 인라인 자산을 제거하거나 보관 위치로 옮긴다.
- [ ] `backend/src/anseong_ai_map/__init__.py`의 콘솔 명령이 인사말만 출력한다. 실제 API 실행 명령으로 연결하거나 `[project.scripts]` 항목을 제거한다.
- [ ] 완료된 과거 계획 문서의 실행 중 PID·서버 상태 같은 시점성 기록은 현재 상태로 오해되지 않게 표시한다.

완료 조건: 모든 추적 파일에 현재 용도가 있고, README와 실행 명령이 실제 진입점을 가리킨다.
