# 실제 데이터 연동 준비

## 현재 상태

- 대시보드는 [simulation.js](./src/data/simulation.js)의 가상 교통 데이터를 사용합니다. 교차로명과 위치는 지도 표시용 참고값이며, 교통량·속도·대기시간은 실제 측정값이 아닙니다.
- [trafficService.js](./src/services/trafficService.js)는 아직 시뮬레이션 데이터를 반환합니다. [backend/main.py](../backend/main.py)의 `/places` API는 교통 데이터 API가 아니며, 데이터도 메모리에만 저장됩니다.
- 지도 바탕은 OpenStreetMap이며, 교통 관측 데이터와는 별도입니다.

## 화면에 필요한 데이터

| 데이터 | 필수 필드와 단위 | 참고 |
|---|---|---|
| 교차로·도로 구간 기준정보 | 고유 ID, 명칭, 행정구역, 위도·경도, 원천 데이터의 교차로/노드/링크 ID | 서로 다른 데이터 출처를 같은 위치에 연결할 기준표가 필요합니다. |
| 교통 관측값 | 관측시각, 구간 ID, 방향, 집계 구간(초/분), 교통량(대/구간 또는 대/시간), 평균속도(km/h), 통행시간·지체시간(초) | 원천 데이터가 제공하는 항목만 표시하고, 단위와 수집주기를 함께 저장합니다. |
| 신호·대기 관측값 | 관측시각, 신호주기(초), 방향별 녹색시간(초), 평균대기시간(초), 대기행렬 길이(m) | 교통량·속도만으로 실제 신호주기나 대기시간을 알 수 없습니다. 교통센터·신호제어기·현장 센서의 별도 자료가 필요합니다. |
| 시간대별 차트 | 시간 구간 시작시각, 실제 집계 교통량, 실제 집계 대기시간 | 누락된 값은 0으로 채우지 말고 `null`로 두어야 합니다. |
| 데이터 출처·신선도 | 제공기관, 원천 ID, 관측시각, 수집시각, 데이터 기준일, 실시간/통계 구분 | 오래된 통계와 실시간 관측값이 섞이지 않도록 표시합니다. |

프론트엔드와의 정규화 응답은 다음 규칙을 권장합니다.

- 최상위 필드: `source`, `dataStatus`, `generatedAt`, `intersections`, `hourlyTraffic`, `summary`
- 교차로 필드: `id`, `sourceId`, `name`, `area`, `position`, `observedAt`, `trafficVolume`, `averageSpeed`, `averageWait`, `congestion`, `status`, `greenRatio`, `directions`
- `position`은 현재 Leaflet 컴포넌트와 동일하게 `[위도, 경도]` 순서로 전달합니다. GeoJSON이나 일부 원천 데이터의 `[경도, 위도]`와 혼동하지 않도록 변환 단계에서 확인합니다.
- 측정하지 않은 `averageWait`, `greenRatio`, `directions` 등은 `null`로 유지하고 화면에는 “자료 없음”으로 표시합니다. 실제 데이터처럼 보이는 0이나 임의 시뮬레이션 값으로 대체하지 않습니다.
- `congestion`을 원천에서 받지 않고 속도 등으로 계산한다면 계산식·기준속도·기준일을 저장하고 “계산값”으로 구분합니다.
- 시간은 `Asia/Seoul` 기준 ISO 8601 오프셋을 포함합니다(예: `2026-11-18T08:00:00+09:00`). 교통량은 관측 구간을 명시해 대/시간과 대/5분을 구분합니다.

## 확인한 공공 데이터 후보

| 출처 | 제공 내용 | 적용 범위와 주의점 |
|---|---|---|
| [경기도 구간 소통 정보 API](https://www.data.go.kr/data/15059534/openapi.do) | 도로 구간 속도, 지체시간, 교통량. 공공데이터포털 안내상 실시간·XML API | 우선 검토 후보입니다. 안성시 내 대상 도로·링크 ID와 호출 주기, 인증·이용 조건을 실제 API 활용가이드에서 확인해야 합니다. 교차로 신호주기나 방향별 대기시간을 제공한다고 가정하면 안 됩니다. |
| [국토교통부 교통소통정보 API](https://www.data.go.kr/data/15040463/openapi.do) | 고속도로·국도의 실시간 구간 속도 및 소통 정보 | 일반 시가지의 모든 도로를 포괄하는 자료는 아닙니다. 안성시 내 국도·고속도로 구간의 보완 자료로 검토합니다. |
| [국토교통부·한국건설기술연구원 교통량 통계 API](https://www.data.go.kr/data/15097077/openapi.do) | 도로 유형·지점·기간별 시간대/일/월/연 교통량 통계 | 공공데이터포털 안내상 갱신 주기는 연간입니다. 과거 패턴 분석에 적합하며 실시간 교통현황으로 표시하지 않습니다. |
| [소상공인시장진흥공단 상가(상권)정보 API](https://www.data.go.kr/data/15012005/openapi.do) | 상호·업종·주소·좌표 등 영업장 정보 | 점포 위치·업종 분석용입니다. 이 API만으로 공실을 판정할 수 없으며, 공실 데이터는 별도 행정·현장 자료가 필요합니다. |
| [경기데이터드림](https://data.gg.go.kr/) | 경기도 공공데이터 및 통계 탐색 | 데이터셋별 제공 형식, 기준일, 재사용 조건을 확인한 뒤 사용합니다. |

## 아직 확보가 필요한 데이터

- 안성시 교차로별 방향·시간대 교통량과 실제 평균 대기시간
- 안성시 신호등 위치, 신호주기, 방향별 녹색시간 및 변경 이력
- 관측값과 교차로를 안정적으로 연결할 공식 교차로·도로 노드/링크 ID
- 공실을 실제로 확인할 수 있는 기준일·주소 단위 자료

공공데이터포털에서 `안성시 교통` OpenAPI 검색 결과가 없었던 점(2026-11-18 확인)을 고려해, 안성시 또는 경기도 교통정보센터에 데이터 보유 여부·제공 범위·갱신 주기·이용 허가를 별도로 문의해야 합니다. 타 지역 전용 데이터(예: 서울시 교차로 신호 운영 API)를 안성시 실측값으로 사용하지 않습니다.

## 연동 순서

1. 후보 API의 활용 신청 및 안성시 공간 범위·필드·갱신주기를 확인합니다.
2. 원천 교차로/노드/링크 ID와 화면의 교차로 ID를 연결하는 매핑표를 만듭니다.
3. API 키가 필요한 경우 백엔드 환경변수에 보관하고, 브라우저 코드에 노출하지 않습니다.
4. 백엔드에서 원천 응답을 정규화하고 `source`, `observedAt`, 단위, 기준일을 함께 반환합니다.
5. 실제 관측·과거 통계·계산값·시뮬레이션을 화면에 명확히 구분하고, 수집 실패와 결측을 별도로 표시합니다.

> 출처와 제공 범위는 2026-11-18에 공공데이터포털 및 기관 사이트에서 확인했습니다. 실제 연동 전에는 각 API 활용가이드, 최신 갱신일, 이용 조건을 다시 확인하세요.
